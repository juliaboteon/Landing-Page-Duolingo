# 🦉 Duolingo Landing Page Clone

Este projeto é uma recriação responsiva da página inicial do Duolingo. O objetivo principal foi praticar a estruturação de layouts modernos, alinhamento de componentes e boas práticas de design responsivo.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação e semântica.
* **CSS3:** Estilização customizada, efeitos de *hover*/*active*.
* **Bootstrap 5:** Sistema de grid, classes utilitárias e responsividade (mobile-first).

## 💻 Destaques do Projeto
* **Design Responsivo:** Adaptação fluida para dispositivos móveis, tablets e computadores, garantindo a proporção dos elementos.
* **Componentização de UI:** Construção da estrutura de cartões de assinatura e rodapé organizado em colunas.
* **Customização de Framework:** Sobrescrita de estilos nativos do Bootstrap via CSS para atingir a identidade visual exata do Duolingo.
